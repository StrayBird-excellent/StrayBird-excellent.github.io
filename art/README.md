# 风又起时

一个不介绍人的个人主页。

它不是简历、不是作品清单、不是「关于我」。它是一幅会呼吸的水墨——你停留多久，它才展开多少。

## 这是什么

- **开场没有信息**。只有山、水、树、几滴雨，和一行竖排的字。
- **点击画面**，长卷才展开。不点，它就一直安静地待着。
- **画面随时辰变色**。清晨、正午、黄昏、夜里，同一座山，四种墨。
- **每一笔都是随机生成的**。山的高度、树的位置、叶子的疏密，每次刷新都不同。
- **关掉长卷**，画还在那里。它不是一个网站，是一扇窗。

## 结构

```
art/
├── index.html      页面骨架、排版、动效（无框架）
├── content.js      ← 所有文字都在这里。想改内容只动这一个文件
├── app.js          画布的绘制流程、长卷的展开逻辑
├── watercolor.js   笔触引擎（零依赖，约 450 行）
├── build_fonts.py  字体子集化脚本（只在改文案后需要重跑）
└── assets/fonts/   自托管的两个字重，共约 250 KB
```

## 笔触引擎

`watercolor.js` 里只有一件事是重要的：`stroke()`。

一条折线的每个顶点，取前后方向的角平分线当法线，沿法线向两侧推出一个**带噪声的宽度**，把两条边缝成一个闭合形状，然后填充。

```js
const a1 = atan2(pts[i][1] - pts[i-1][1], pts[i][0] - pts[i-1][0]);
const a2 = atan2(pts[i][1] - pts[i+1][1], pts[i][0] - pts[i+1][0]);
let a = (a1 + a2) / 2;            // 角平分线 = 法线
left.push([x + w*cos(a), y + w*sin(a)]);
right.push([x - w*cos(a), y - w*sin(a)]);
```

这比直接 `ctx.stroke()` 多出来的东西，就是「笔意」：
两端会自然收细，边缘因为噪声而毛糙，多根半透明的笔触叠在一起时会互相渗色。

其余都是它的组合：`dab()`（一枚带噪点的墨点）、`wash()`（一片化开的淡墨）、
`tree()` / `mountain()` / `mist()`（用上面三个搭出来的意象）。

## 改内容

打开 `content.js`：

| 键 | 是什么 |
|---|---|
| `hero` | 首屏竖排的两列字 |
| `name` / `motto` | 右上角题签 |
| `hint` | 底部那句提示 |
| `chapters[]` | 长卷的每一章。`paras` 里 `t:"verse"` 会排成居中斜体 |
| `chapters[].works[]` | 可选。作品条目，点击展开详情 |
| `chapters[].traces[]` | 可选。联系方式，`href` 为空则点击复制 |
| `sealText` | 红印上的那个字 |

改完文案后，如果用了新字，重跑一次字体子集：

```bash
pip install fonttools brotli
python build_fonts.py
```

否则新字会用系统字体兜底（能显示，只是字形不统一）。

## 本地预览

直接双击 `index.html` 即可（纯静态，无需构建）。

## 部署

和目录下的主站一样，推上 GitHub 后用 Pages 发布即可。整个 `art/` 目录可直接作为独立站点根目录。

## 一点说明

- 尊重 `prefers-reduced-motion`：关掉动画时雨会停，但画面本身不动。
- 无外部依赖、无 CDN、无需联网字体。
- 首屏只有一个 Canvas，树的绘制是一次性的，滚动时不重绘。
